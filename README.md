# CriticLens

**Can critic sentiment predict a movie's long term streaming value?**

A data analytics project that scrapes IMDB Top 250, analyzes critic review sentiment, 
and identifies which movies represent strong long term streaming licensing bets vs short term hype.

## Tech Stack
- Python
- BeautifulSoup
- VADER Sentiment Analysis
- Pandas
- Matplotlib / Seaborn
- Streamlit

## Project Structure
- data/ — raw and processed datasets
- notebooks/ — analysis notebooks
- scripts/ — scraping and processing scripts
- visuals/ — exported charts
- app/ — streamlit dashboard
